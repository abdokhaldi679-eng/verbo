# Code de conduite

## Notre engagement

Nous voulons un projet accueillant, respectueux et sûr pour toutes les personnes qui
apprennent, enseignent, traduisent, testent ou développent Verbo, quels que soient leur âge,
leur origine, leur langue, leur identité, leur niveau technique ou leur expérience.

## Comportements attendus

- Être respectueux et constructif dans les issues, les pull requests et les discussions.
- Critiquer les idées, pas les personnes.
- Accepter les retours et reconnaître ses erreurs.
- Aider les débutants et expliquer les décisions techniques.
- Respecter la licence MIT et le travail des autres contributeurs.

## Comportements inacceptables

- Insultes, menaces, harcèlement ou discrimination.
- Contenu sexuel, violent ou illégal.
- Publication de données personnelles sans consentement.
- Spam, publicité ou tentative de détournement du projet.
- Publication d’une faille de sécurité non corrigée : voir [SECURITY.md](./SECURITY.md).

## Responsabilités des mainteneurs

Les mainteneurs peuvent supprimer, modifier ou refuser tout contenu qui ne respecte pas ce
code, et expliquer leur décision. Ils s’engagent à traiter les signalements de manière juste,
confidentielle et rapide.

## Portée

Ce code s’applique à tous les espaces du projet : dépôt GitHub, issues, pull requests,
discussions, releases, réseaux sociaux et événements liés à Verbo.

## Signaler un problème

Contacte le mainteneur du dépôt via son profil GitHub
([@abdokhaldi679-eng](https://github.com/abdokhaldi679-eng)) en décrivant les faits, les
personnes concernées et les liens utiles. Les signalements sont traités confidentiellement.

## Sanctions

Selon la gravité, les mesures peuvent aller d’un avertissement à l’exclusion temporaire ou
définitive du projet, sans préjudice des règles de GitHub.

## Attribution

Ce code s’inspire du [Contributor Covenant](https://www.contributor-covenant.org/), version
2.1, adapté en français pour Verbo.
